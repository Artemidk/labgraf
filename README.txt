Построение графика для лабораторной работы — пакет сайта

Содержимое: index.html (программа), manifest.webmanifest, sw.js, иконки.
Загрузите ВСЕ файлы в одну папку (корень сайта) на любом хостинге статических сайтов.

Вариант для России (без VPN): Yandex Cloud Object Storage
1. Зарегистрируйтесь в Yandex Cloud, создайте облако и каталог.
2. Object Storage -> Создать бакет. Имя без точек (тогда HTTPS работает сразу), доступ на чтение объектов — публичный.
3. В бакете откройте вкладку «Веб-сайт» (хостинг), включите хостинг и укажите главную страницу index.html.
4. Загрузите в бакет все файлы из этой папки.
5. Откройте адрес из поля «Ссылка» в настройках хостинга.
Тарификация: хранение, операции и исходящий трафик по тарифам Object Storage (для сайта в сотни КБ расходы минимальны; актуальные условия смотрите у Yandex Cloud).

Без хостинга: отправьте друзьям один файл index.html (например, в Telegram или ВК). Он открывается в браузере и работает без интернета; данные сохраняются в браузере.
Установка как приложения (значок на экране телефона) работает только при открытии сайта по ссылке https://.
